d2note 本地智能笔记编辑器

🐰 为 macOS 而生的轻量代码 / 笔记编辑器

Swift + AppKit 原生编写，零第三方依赖。语法高亮、本地翻译、习惯推荐、自动保存草稿 —— 你的内容永远只留在你的 Mac 上。

多标签 · 行号 · 语法高亮 · 中文右键菜单 · 底部状态栏一键翻译

功能特性

向 Notepad++ 致敬，但长在了 macOS 上。

多标签页

拖拽排序、双击新建、⌘1-9 快速切换、未保存圆点标记，标签上还有文件类型彩色徽章。

20 种语言语法高亮

手写 UTF-16 tokenizer：Swift、Python、JS/TS、C/C++、Go、Rust、JSON、Markdown、SQL…打开文件自动识别语言。

本地翻译 macOS 26+

基于系统 Translation 框架完全离线翻译，自动识别源语言，结果一键替换。内容不出你的电脑。

自动保存草稿

未命名标签、未保存修改、光标位置全部持久化，重启后原样恢复。文件被删了？草稿还能救回来。

智能推荐 默认关闭

NLTokenizer 本机分词学习你的用词习惯，输入时幽灵文本补全，Tab 接受。隐私优先，数据只在本地。

快速格式化

JSON 格式化/压缩、XML/HTML 美化/压缩、SQL 美化、排序/倒序/去重/删空行，右键一键直达。

编辑辅助

括号引号自动补全与跳过、括号配对高亮、回车智能缩进、⌘/ 切换注释、查找替换（支持正则）。

深度系统集成

Dock 菜单与徽标、系统服务「用 d2note 打开所选文本」、标题栏代理图标、拖拽打开、中文右键菜单。

深浅双主题

One Dark 风深色主题与 Xcode 风浅色主题一键切换，字号 ⌘= / ⌘- 随手调。

效率党的最爱。

只要装了 Xcode，一条命令。
